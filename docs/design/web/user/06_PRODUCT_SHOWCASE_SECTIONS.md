# Purpose

This document defines the **complete product showcase experience** for the FinanceOS website.

The showcase section is inspired by premium Etsy digital product listings, Apple product pages, and Linear feature pages.

Instead of displaying random screenshots, every screenshot tells a story and explains a feature.

This document is the **single source of truth** for Cursor when building the gallery, screenshots, feature callouts, comparison layouts, and media presentation.

---

# Showcase Philosophy

FinanceOS is a visual product.

Visitors must understand what they are buying without watching a video.

Every screenshot answers one question:

> **"What can I do with FinanceOS?"**

# Screenshot Presentation Rules

All screenshots use the same presentation style.

### Window Frame

- Rounded 24px corners.
- Mac-style window controls.
- Soft shadow.
- Glass border.

### Background

- Gradient surface.
- Floating glow.
- Soft blur.

Never place screenshots directly on page background.

---

# Screenshot Quality Standards

Every screenshot must be exported at high resolution.

## Requirements

- Retina quality.
- Crisp typography.
- No compression artifacts.
- Dark Theme screenshots by default.

Light Theme screenshots shown separately.
