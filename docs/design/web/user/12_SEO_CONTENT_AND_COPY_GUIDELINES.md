# Purpose

This document defines the complete **SEO strategy, copywriting system, metadata structure, URL strategy, structured data, and content guidelines** for the FinanceOS website.

This document ensures:

- High Google search visibility.
- Consistent brand messaging.
- Conversion-focused copywriting.
- Technical SEO implementation.
- Future blog/documentation scalability.

This is the **single source of truth** for Cursor when implementing SEO and website content.

---

# SEO Philosophy

FinanceOS is a **product-first website**, not a blog-first website.

SEO has two goals:

1. Rank for high-intent finance spreadsheet keywords.
2. Convert visitors into customers.

Every page must satisfy both search intent and purchase intent.
